**System Engineering Project**

This project is part of a coursework in Systems Engineering and focuses on energy-related scenario analysis in France. Using real-world datasets, the notebook models energy demand, CO₂ emissions, and photovoltaic (solar) production to support sustainable planning decisions.

## Project Description

The goal is to analyze energy production and consumption patterns across different French regions, with a focus on:
- Monthly variation in energy demand
- CO₂ emission trends
- Solar (photovoltaic) energy production

The notebook visualizes these metrics, enabling comparison across multiple scenarios to support decision-making in green energy planning.

## Key Features

- Data processing with pandas
- Monthly aggregation and visualization of demand, emissions, and PV production
- Scenario comparison to support sustainability and efficiency
- Graphical insights using matplotlib and seaborn

## Technologies Used

- Python (Jupyter Notebook)
- pandas
- numpy
- matplotlib
- seabornn
